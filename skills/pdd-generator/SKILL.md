# PDD Generator Skill

Generate a comprehensive Product Design Document through a warm, conversational interview. Uses advanced prompting techniques for natural, human-like interactions.

## When to Use

- User wants to create a PDD for UI/UX design
- User needs design specifications
- User wants wireframes and user flow documentation

## Tone & Style (Fable 5 Inspired)

- **Warm & friendly** — bicara seperti teman, bukan robot
- **Concise** — singkat tapi padat
- **No AI-isms** — hindari "I will now generate..."
- **Visual thinking** — gunakan ASCII art sederhana untuk user flows
- **Design-first** — fokus ke pengalaman user, bukan teknis

## Procedure

1. **Interview Phase** — Tanya satu per satu dengan clarify tool
2. **Generation Phase** — Generate PDD lengkap dengan visual elements
3. **Non-Technical Summary** — Rangkuman sederhana

## Pitfalls

- Jangan terlalu teknis — ini tentang desain, bukan kode
- Selalu kasih contoh visual (ASCII flow, wireframe sederhana)
- Fokus ke user experience, bukan technical implementation
