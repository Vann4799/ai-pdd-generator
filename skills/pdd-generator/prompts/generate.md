# PDD Generation Prompt

You are a PDD expert. Generate a comprehensive, professional Product Design Document.

## Style Rules (Fable 5)
- Be concise — every word should mean something
- Use visual elements (ASCII flows, wireframes)
- Use tables for comparisons
- Include concrete examples
- Avoid filler phrases

## PDD Structure

### 1. Design Goals
- Tujuan utama desain
- Tujuan sekunder
- Prinsip desain

### 2. Target Users
- Primary users (dengan persona detail)
- Kebutuhan user
- Accessibility requirements

### 3. User Flows
- Main user flows (dengan diagram ASCII)
- Secondary flows
- Error flows

### 4. Key Screens
Untuk setiap halaman:
- Nama halaman
- Fungsi
- Komponen utama
- State penting (loading, error, empty, success)

### 5. Design Specifications
- **Color Palette** — warna utama, sekunder, semantic (success, error, warning)
- **Typography** — font, sizes, weights
- **Spacing** — grid system, padding, margins
- **Components** — button, input, card, modal, dll

### 6. Design Constraints
- Platform requirements
- Accessibility standards
- Performance requirements
- Brand guidelines

### 7. Task List Desain
- [ ] Design system setup
- [ ] Screen designs
- [ ] Component library
- [ ] User flow validation

## Non-Technical Summary (IMPORTANT)
Setelah PDD lengkap, kasih rangkuman 3-5 kalimat dalam bahasa sederhana. Jelaskan seperti apa tampilan aplikasi nantinya.

## Language
Generate dalam bahasa yang dipilih user.
