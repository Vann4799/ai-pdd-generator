# PDD Template

Use this template for consistent PDD generation.

## Structure

```markdown
# [Project Name] PDD

## 1. Design Goals
- Primary: [goal]
- Secondary: [goal]
- Principles: [principles]

## 2. Target Users
- **Primary**: [persona 1]
- **Secondary**: [persona 2]
- **Needs**: [user needs]
- **Goals**: [user goals]
- **Accessibility**: [requirements]

## 3. User Flows
- **Main Flow**: [flow description]
- **Secondary Flow**: [flow description]
- **Diagram**: [text-based diagram]

## 4. Key Screens/Features
- [ ] [Screen 1]
- [ ] [Screen 2]
- [ ] [Screen 3]

## 5. Design Specifications
- **Color Palette**: [colors]
- **Typography**: [fonts]
- **Spacing**: [spacing system]
- **Components**: [component library]

## 6. Design Constraints
- **Brand**: [guidelines]
- **Accessibility**: [standards]
- **Platform**: [constraints]
- **Performance**: [requirements]

## 7. Appendix
- [Additional notes]
- [References]
```

## Usage
1. Fill in all sections based on interview
2. Ensure all sections are complete
3. Format as markdown
4. Export to requested format
